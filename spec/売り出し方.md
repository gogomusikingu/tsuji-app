# 売り出し方（整理前の 7 章）

## 7. 売り出し方（2026-10-19 決定）

### 7.1 位置づけ
- 「占いアプリ」ではなく「迷いを偶然に預けるための意思決定ツール」
- コピーの軸: 「ルーレットは自分の選択肢の中でしか選べない。この書は、選択肢の外から答えを持ってくる」
- 主役は「書をひらく」1つに絞る（メニュー機能は削除済み）
- 占いではなく「考えるための道具」として伝わる見せ方をする（App Store の審査の分類も同じ考え方で選ぶ）

### 7.2 市場調査の要点（2026-10-19）
| 種類 | 代表例（日本の App Store 評価件数） | 中身 | このアプリとの違い |
|---|---|---|---|
| ランダム決定 | ルーレット!（約5.4万）、ルーレット - 迷った時の抽選（約4.6万）、即決（約1,300） | 自分で入れた選択肢から1つ選ぶ | 選択肢の外から言葉が来る |
| 聖句アプリ | 聖書: 今日の聖句（120）、今日のマナ | 状況に合う聖句を選んで届ける（信仰者向け） | 完全な無作為。信仰不要 |
| おみくじ | 毎日おみくじ（約710） | 運勢を告げる | 答えは告げない。読み解くのは本人 |
- 需要が大きいのは「迷ったら決めてほしい」層。聖句アプリやタレブ読者は規模が小さい／不明
- ルーレット系の主な不満: 広告による中断、データ消失・不具合、「本当にランダムか」への不信
- おみくじの「凶でも取り消せない」は短所とされているが、このアプリでは「引き直せない作法」として長所にする
- 日本語で「無作為に聖書の一節を引いて意思決定に使う」アプリは見当たらない

### 7.3 方針
- 入口は「迷ったら」「決断」「ランダム」（検索語）。聖書・タレブは入口ではなく、「なぜこの方法か」を伝える物語として説明文・体験記で使う
- 売りの言葉（ほかのアプリで不満が多い点を、このアプリでは解消する）: 広告なし／偏りのない本物の無作為（暗号用の乱数）／記録は端末内で消えない／引き直しなしで迷いが終わる
- 主なターゲット: 決断疲れの会社員、ビジネス書読者。占いを楽しみたい人より、決めることに疲れた人に向ける
- 見せ方: 名前・アイコン・スクリーンショットに「占い・運勢」の言葉や見た目を使わない。カテゴリは「ライフスタイル」
- 広め方: 作者自身の実践記（例:「30日間、迷ったら書をひらいて従ってみた」）を note / X で発信する
- 配慮: 聖書への敬意と「信仰の代わりではない」ことを説明文に明記する

### 7.4 アプリ名とデザイン（2026-10-19 決定）
- 日本語名: **辻**、副題: **迷ったら、偶然の一節に問う**（英語名: Tsuji、副題: In doubt? Ask a chance verse）
  - 「辻」だけでは何のアプリか伝わらないため、副題を先に大きく見せる
  - 英語名を Sortes から Tsuji に変更（2026-10-20）: App Store に同名の「Sortes: Decision Maker」（コイン・サイコロで決める道具）があり、
    同じ用途で重なるため。日本語名とそろえ、英語圏では由来を知らなくても通じる固有名として使う。
    日本語名は「ひとふし」とも比較したが、副題と意味が重なり、和歌集を足すと合わなくなるため「辻」を維持
  - 「問う」にした理由（2026-10-19）: 迷いを持って一節に尋ねる使い方そのもので、由来の万葉集「夕占問ふ」とつながる。
    「きく」より余韻のある響きで、画数の多い漢字が続いたあとも「問う」の形で文がやわらかく閉じる。常用漢字
  - App Store の名前: 「迷ったら、偶然の一節に問う｜辻」（検索で見つかり内容が伝わる。30文字以内）
  - ホーム画面のアイコン名: 「辻」（長い名前は途中で切れるため）
  - 副題に「占い・おみくじ」は使わない（占いアプリではなく、考えるための道具として伝えるため）
  - 辻 = 道が交わる場所・人が行き交う往来。「分かれ道（迷い）」と「偶然の言葉に出会う場所」の両方を表す
  - 由来: 『万葉集』の時代からある辻占（辻で偶然聞いた言葉で迷いを確かめる）。初回説明で万葉集の歌（巻11・2506）を紹介する
  - 「しおり／栞」は旅行・読書アプリと名前が重なるため不採用（栞は一節が出る演出に残す）
- 言葉づかい: 「占う・告げる・運勢」は使わず、「ひらく・読む・こじつける・決める」を使う（占いとの区別は色より言葉でつける）
  - 「書をひらく」は1日1回の儀式（無作為に一節を引く）だけに使う。対になるのは「書を閉じる」
  - 引いた一節をもう一度見るのは「読み返す」。ここで「ひらく」を使うと、新しく引けると誤解されるため
- アイコン（2026-10-19 決定・I2案）: 分厚い聖書を開いた形を、直線と円弧だけで描く線画。右ページに朱の線を1本だけ入れ、
  「ひらいた一節」を表す（差し色の朱はこの1本だけ）
  - 線は2種類の太さ: 外形（ページの上辺・両側・ページの束の底）を太く、内側（ページと小口の境目・綴じ目）を細く
  - 本はやや正面から見た角度。ページは綴じ目から弓なりに反り、下に小口の厚みを持たせる（聖書の分厚さ＝運命的な一節との出会い）
  - 道（Y字路）の案は、主張が強く虫のように見えたため不採用。図形は `Theme.swift` の `TsujiMark`
- 言葉づかい: 「占う・告げる・運勢」は使わず、「ひらく・読む・こじつける・決める」を使う（占いとの区別は色より言葉でつける）
  - 「書をひらく」は1日1回の儀式（無作為に一節を引く）だけに使う。対になるのは「書を閉じる」
  - 引いた一節をもう一度見るのは「読み返す」。ここで「ひらく」を使うと、新しく引けると誤解されるため
- アイコン（2026-10-19 決定）: 道の上に開いた本が置かれ、道はその先で二股に分かれる（土色の灰の道・墨の本・生成りの地）
  - 本と道の根元は同じ消失点に、分かれた2本の道はそれぞれの消失点に向かい、先端は尖って消える（地平線は描かない）
  - 右ページに朱の線を1本だけ入れ、「ひらいた一節」が浮かぶことを表す。差し色の朱はこの1本だけにする
    （道を朱にすると主張が強く、角のある虫のように見えたため）
  - iPhone の角丸で先端が欠けないよう、全体を95%に縮めて余白を取る。図形は `Theme.swift` の `TsujiMark`
- 字体: 引用文（一節・前後の節・例の引用・記録・シェア画像）は「しっぽり明朝」（明治期の活字がもと。アプリに同梱）、
  それ以外はヒラギノ明朝。`Theme.verse()` / `Theme.mincho()`
- 画面: ミニマル・モダン。生成り色の背景、墨色の文字、本文は明朝体、差し色は朱1色。紫・金・星・水晶玉・羊皮紙・十字架は使わない
