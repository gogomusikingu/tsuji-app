# 技術方針（整理前の 4 章）

## 4. 技術方針
- 共通: サーバーなし。聖書本文はアプリに同梱し、記録は端末（Web 版はブラウザ）の中だけに保存する。
  秘密の鍵・外部 API は持たない（公開しても守るものがない構成にする）
- 乱数: 偏りのない、暗号用の乱数を使う
- Mac / iPhone 版: Swift / SwiftUI。記録は JSON、画面文字は `Language.swift` の表で管理
- 起動: 聖書本文（約3万1千節）は起動画面の間に裏で読み込む（`Bible.shared`。読み込み自体は約0.4秒）
- iPhone の起動画面（アプリ準備中に OS が出す画面）に、生成り色の背景と辻マークを設定（`ios/Info.plist` の UILaunchScreen、
  `LaunchBackground` / `LaunchQuiet`）。アプリ内の起動画面はマークを同じ位置（画面中央）に置き、途切れずにつながる。
  アイコンを変えたら `--render-previews` で `LaunchQuiet@1x〜3x.png` を作り直して差し替える
  （iPhone は起動画面を一時保存するため、絵を変えたら画像の名前も変えて読み込み直させる）
- Web 版: 画面だけのサイト（静的サイト）として GitHub Pages に置く（4.3）。記録はブラウザの localStorage

### 4.1 Mac 試作版（MVP・2026-10-19）
- Xcode なしで動く Mac アプリ（Swift Package / SwiftUI）。iPhone 版にコードを流用する前提
- 実装済み: 3.1 書をひらく（3秒の集中→ページをめくる動き→振動）、引き直し防止（1時間）、
  3.2 振り返り（直後の解釈・行動、記録タブで「その後どうなった？」を後から記入）、日本語/英語切替
- デザイン反映済み（7.4）: `Theme.swift` に配色（生成り #F5F0E6・墨 #2B2927・朱 #C64730）、明朝体（ヒラギノ明朝）、
  辻マーク（7.4）を定義。ヘッダーに「迷ったら、偶然の一節に問う」（大）と「辻」（小）、一節の頁に朱の栞、
  初回説明に万葉集の歌と辻占・古代ローマの由来を表示。英語版の表示名は Tsuji
- 起動画面: 辻マーク → 「迷ったら、偶然の一節に問う」 → 「辻」の順にふわっと表示し、約4.5秒で本画面へ（初回はその後に説明を表示）。
  画面を押すと飛ばせる。一般的な目安（2〜3秒、毎日使うアプリはさらに短く）より長いが、
  一節をひらく前の「ひと呼吸」として意図的に長くしている
- 見た目の確認: `RandomOracle --render-previews <フォルダ>` で主要画面を PNG に書き出せる（画面収録の権限なしで確認するため）
- 引いた時点で記録に自動保存する（途中で閉じて引き直すことを防ぐため）
- 記録は端末内の JSON（`~/Library/Application Support/RandomOracle/journal.json`）
- ビルドの注意: Command Line Tools の macOS 27 SDK は SwiftUI のマクロが使えないため、
  macOS 26 SDK を指定してビルドする（`tools/run_mac.sh`）。テストは Swift Testing（XCTest は Xcode が必要）。
  テストファイルを変更した直後の1回目は「TestingMacros が見つからない」と失敗することがあり、もう一度実行すると通る

### 4.2 iPhone 版（2026-10-19 移植）
- `ios/Tsuji.xcodeproj`: Mac 試作版と同じ `Sources/RandomOracle` のコードをそのまま使う（Xcode のフォルダ同期機能）。
  Mac / iPhone の違いは `#if os(...)` と `Platform.swift` で吸収
- iPhone 独自: 画面下のタブバー（ひらく／記録）、
  書を閉じてから3日後に「その後どうなりましたか？」の通知（`Followup.swift`）
- アプリ表示名「辻」、バンドル ID `com.gogomusikingu.tsuji`、iOS 17 以上、iPhone 縦向きのみ。
  アイコンは辻マークから生成（`ios/Tsuji/Assets.xcassets`）
- シミュレーター: iOS 27.1（この環境で作成できる端末は iPhone Duo のみ）。Simulator の画面アプリが Xcode に見当たらないため、
  操作して確認するときは Xcode でプロジェクトを開いて ▶ を押す
- 確認用: Debug ビルドで環境変数 `TSUJI_AUTODRAW=1` を付けて起動すると自動で書をひらく（スクリーンショット用）。
  `TSUJI_TAB=records` で記録タブから起動する
- テスト中の便宜: Debug ビルドは、新しくビルドするたびに（Xcode の ▶ など）1日1回の制限が解除され、書をひらき直せる。
  本番（Release）ビルドでは解除されない
- 保存は試作版と同じ JSON、画面文字も同じ表のまま（SwiftData・String Catalog への移行は必要になってから）

### 4.3 Web 版（2026-10-20 作成）
- 機能: 3.1 書をひらく、3.2 書き込み（数日後の通知は除く）、3.3 シェア。見た目・文言・演出の時間は iPhone 版にそろえる（7.4・3.5）
- 作り: 画面だけのサイト（HTML / CSS / JavaScript。ビルド不要）。`web/core.js` に文言・聖書の扱い・書き込みの規則、
  `web/app.js` に画面、`web/mark.js` に辻マーク（`TsujiMark` と同じ図形）
- 聖書本文は書ごとのファイル（`web/data/<書>.tsv`）に分け、ひいた節の書だけを読み込む（全体 9MB を毎回読ませないため）
- 字体: しっぽり明朝を、聖書と画面で使う文字（約2,200字）だけに絞って 0.44MB にした（`web/fonts/verse.woff2`）。
  それ以外の文字はヒラギノ明朝（なければ游明朝など）
- 記録はブラウザの中（localStorage）だけに保存し、外へ送らない。別のブラウザ・端末とは共有されない
- 引き直し防止: 書をひらいた瞬間に「どの節か」と時刻を保存してから演出を始める。途中でページを閉じても、
  次に開いたときにその節が今日の一節として記録される
- 言語: 初回はブラウザの言語に合わせる（日本語以外なら英語）。右上で切り替え
- シェア: 画像を作り、スマホでは共有画面（LINE・X など）へ。共有できないブラウザ（多くのパソコン）では画像を保存する
- 振動: 対応するブラウザ（Android など）だけ。iPhone の Safari は振動に対応していない
- ホーム画面に追加すると、アプリのように全画面で開く（`manifest.webmanifest`、アイコンは iPhone 版から縮小）
- 生成物（`web/data/`・`web/fonts/`）は Git に入れず、`tools/build_web.py` で作る。公開時は GitHub Actions が作って載せる
  （`.github/workflows/pages.yml`。`main` への push で動き、https://gogomusikingu.github.io/tsuji-app/ に載る。
  `dev` は作業用で、公開されるのは `main` だけ。公開を許すブランチは Settings → Environments → github-pages で `main` を指定）
- 確認用: URL に `?cooldown=10` を付けると、10秒で書をひらき直せる
- テスト: `node --test web/tests/*.test.js`

### 4.4 ディレクトリ構成
```
Package.swift
Sources/RandomOracle/        アプリ本体（App / ContentView / DrawView / Notes / RecordsView / Share / Bible / Journal / Cooldown / Language / Examples / Theme / Previews）
Sources/RandomOracle/Resources/bible.tsv   聖書本文（書・章・節・日本語・英語）31,098節
Sources/RandomOracle/Resources/name_lists.tsv  引く対象から外す、名前を並べただけの節（tools/find_name_lists.py で作る）
Sources/RandomOracle/Resources/ShipporiMincho-*  引用文用の字体（しっぽり明朝 Regular）とそのライセンス（SIL OFL 1.1）
Tests/RandomOracleTests/     テスト
tools/build_bible.py         eBible.org のデータから bible.tsv を作る
tools/find_name_lists.py     名前を並べただけの節を探して name_lists.tsv を作る
tools/build_web.py           Web 版の聖書データ・字体・アイコンを作る（tools/.venv の fonttools を使う）
tools/run_web.sh             Web 版をこの Mac で開く（http://localhost:8765/）
web/                         Web 版（index.html / style.css / app.js / core.js / mark.js / tests）
.github/workflows/pages.yml  Web 版を GitHub Pages に公開する（main への push で動く）
Web版を起動.command           Web 版をブラウザで開く（待ち時間10秒）
tools/run_mac.sh             Mac 試作版のビルドと起動
tools/run_ios.sh             iPhone 版をビルドしてシミュレーターで起動（画面なし）
ios/                         iPhone 版の Xcode プロジェクトとアイコン
iPhone版を起動.command        Xcode で iPhone 版を開く
試作版を起動.command          ダブルクリック用の起動ショートカット（待ち時間10秒）
```
